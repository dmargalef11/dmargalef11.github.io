Sobre mí

Desarrollador Junior especializado en Back-End y Data Engineering. Tras mi formación en DAM, en pisos.com trabajé desarrollando APIs en .NET y Python dentro de un entorno de microservicios con DDD y TDD. Además, participé activamente en la creacion de una arquitectura Lakehouse para el equipo de Data, implementando soluciones de almacenamiento, procesamiento de datos y pipelines ETL utilizando tecnologías como MinIO, Iceberg, Trino y dbt.

Cuento además con experiencia creando dashboards analíticos para equipos utilizando Looker Studio y Metabase. Para ello, realizaba tareas avanzadas de data filtering y selección mediante consultas SQL complejas, asegurando que la información fuera accionable y precisa para la toma de decisiones. He presentado estos proyectos a stakeholders, traduciendo métricas técnicas en insights de negocio.

Domino el ciclo completo de los datos y aplico principios de Clean Code y metodologías Agile en mi día a día, utilizando Git para control de versiones y colaboración en equipo. Busco proyectos donde la tecnología tenga un impacto real, explorando actualmente nuevas fronteras en Inteligencia Artificial y diseño de APIs escalables.
